# Competetive Crossplatform Checkers (CCC)

Кроссплатформенные соревновательные шашки с клиент-серверной архитектурой. Проект включает серверную часть, клиент для ПК и клиент для Android.

## О проекте

CCC — проект для игры в шашки по сети. Сервер обрабатывает подключения игроков и синхронизацию ходов, а клиенты позволяют играть с ПК или Android-устройства.

Проект находится в разработке. Интерфейсы и протоколы взаимодействия могут изменяться.

## Состав репозитория

| Папка или файл | Назначение |
|---|---|
| ProjectServer | Серверная часть |
| ProjectClient | Основной клиент для ПК |
| AndroidClient | Клиент для Android |
| ProjectClientTest | Тестовый клиент для проверки взаимодействия |
| server | Дополнительные серверные файлы |
| client_pc | Дополнительные файлы ПК-клиента |
| CompetetiveCrossplatformCheckers - CCC.sln | Решение Visual Studio |

## Требования

- Visual Studio с поддержкой C++ — для сервера и ПК-клиента.
- Android Studio — для сборки Android-клиента.
- Доступ к сети — для игры через сервер.

## Сборка

1. Склонируйте репозиторий командой: git clone https://github.com/Hoodine/CompetetiveCrossplatformCheckers---CCC.git
2. Откройте решение CompetetiveCrossplatformCheckers - CCC.sln в Visual Studio.
3. Соберите нужные проекты: ProjectServer, ProjectClient и при необходимости ProjectClientTest.
4. Для Android откройте папку AndroidClient в Android Studio и соберите APK стандартным способом.

## Запуск

1. Запустите сервер.
2. Запустите клиент для ПК или Android.
3. Подключитесь к серверу.
4. Создайте матч или присоединитесь к игре, если это предусмотрено интерфейсом клиента.

## Использование

Запустите сервер, подключитесь клиентом и играйте в шашки по сети. Если в клиенте есть настройки подключения, укажите адрес и порт сервера.

## Структура проекта

- AndroidClient — мобильный клиент.
- ProjectClient — клиент для ПК.
- ProjectClientTest — тестовый клиент.
- ProjectServer — сервер.
- client_pc — дополнительные файлы ПК-клиента.
- server — дополнительные серверные файлы.
